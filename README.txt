SARFARAZ WEBX PORTFOLIO
=======================

Files
- index.html: complete responsive portfolio website (CSS + JavaScript included).

How to preview
1. Extract the ZIP.
2. Open index.html in Chrome.

How to publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload index.html to the repository root.
3. Open Settings -> Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose main and /(root), then Save.
6. Your site will be published at the GitHub Pages URL shown there.

Before publishing
- Review the project cards. Koco Street Food and Greater Amherst are labelled as website concepts; keep that wording unless you have permission and a public live demo to show.
- The Creamy Ice Cream demo link is set to https://creamyicecream.vercel.app/.
- The contact form uses mailto. It opens the visitor's email app with a pre-filled message; it does not submit to a database. For a true on-page form inbox, connect Formspree or another form backend.
- Update any service, pricing or project claims so they accurately match what you offer.
